# OceanGuard Backend — ML Pipeline
**SIH PS 26143 | NTRO | Oil Spill Detection**

---

## ⚡ Quick Start (5 Steps)

```bash
# 1. Create virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate    # Linux/Mac

# 2. Install PyTorch for CUDA 12.1 (RTX 3050)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# 3. Install remaining dependencies
pip install -r requirements.txt

# 4. Download dataset subset (~4 GB)
python scripts/download_dataset.py

# 5. Preprocess → patch extraction
python preprocess.py

# 6. Train (RTX 3050 optimized)
python train.py
```

## 🎮 RTX 3050 Configuration

| Setting | Value | Reason |
|---|---|---|
| Batch size | 8 | Fits in 4 GB VRAM with AMP |
| Grad accumulation | 4 | Effective batch = 32 |
| Precision | FP16 (AMP) | Halves VRAM usage |
| Encoder | EfficientNet-B0 | Lightweight (4M params) |
| Patch size | 256×256 | GPU-friendly tile size |
| Expected VRAM | ~2.4 GB | Safe for 4 GB card |

## 🏋️ Training Commands

```bash
# Validate setup without training
python train.py --dry-run

# Default training (25 epochs, batch 8)
python train.py

# Custom training
python train.py --epochs 30 --batch 6 --lr 5e-5

# Resume from checkpoint
python train.py --resume models/checkpoint_epoch010.pth

# Monitor training
tensorboard --logdir runs/
```
